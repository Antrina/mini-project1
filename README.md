# Mini Project - Random Question Generator
This is a C Program that generates random questions for users to answer and check their responses.
## Features
- Generates random quiz questions.
- Case- insensitive answer checking.
- Displays feedback.
  ## How to Run
  1. Compile the program:
    gcc Mini_pro.c -o Mini_pro
  2. Run the executable:
     .\Mini_pro
